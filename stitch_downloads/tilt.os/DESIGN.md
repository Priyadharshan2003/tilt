## Brand & Style

This design system embodies a cybernetic bio-interface engineered for high-agency software engineers, technical founders, and elite keyboard athletes. It operates at the intersection of neurological state-tracking and developer workflow instrumentation. The target audience lives in hyper-focus cycles, IDE terminals, and complex mental graphs; they value hyper-dense, legible telemetry combined with atmospheric, calm focus environments.

The visual style blends **Neo-Cybernetic Glassmorphism** with **Technical Minimalism**:
- **Atmospheric Obsidian Depth:** Canvas backgrounds sink into light-absorbent voids to neutralize ocular fatigue during marathon coding sprints.
- **Cognitive State Signaling:** Fluid color choreography visually shifts based on developer physiology and state—from restorative zen teal to electric high-throughput flow, down to volcanic warnings during cognitive overload and tilt.
- **Tactile Bio-glass:** Surface layers use ultra-sheer translucent plates, micro-frosted outer keylines, and ambient glow reflections rather than heavy physical drops.
- **Telemetry Precision:** Pure, mechanical monospaced typography balances an ultra-clean, structural sans-serif UI scaffold.

## Colors

The palette establishes an emotional diagnostic spectrum for developer cognition:
- **Primary (`#2DD4BF` - Zen Teal):** Denotes baseline equilibrium, neural recovery, zero-friction debugging, and focused stability.
- **Secondary (`#A855F7` - Electric Purple):** Represents high-velocity flow states, active deep work, compilation loops, and neural overdrive. Complemented contextually by cyan (`#06B6D4`) during hyper-threading moments.
- **Tertiary (`#F43F5E` - Tilt Crimson / Chaos Amber `#F59E0B`):** Represents high cognitive load, runaway context switching, CPU/RAM thrashing, and cognitive meltdown ("tilt").
- **Neutral Canvas (`#09090B` - Deep Obsidian):** The foundational absolute black void, layered with elevated zinc-sheen grays (`#18181B`, `#27272A`) for deep optical balance.

### Semantic State Applications
- **Surfaces:** Pure semi-transparent zinc-950 (`rgba(9, 9, 11, 0.72)` to `rgba(24, 24, 27, 0.65)`).
- **Keyline Borders:** Subdued structural whites and grays (`rgba(255, 255, 255, 0.08)` to `rgba(255, 255, 255, 0.16)`).
- **Bio-Auras:** Soft chromatic back-glows (10–20% opacity) dynamically driven by current bio-rhythms and keystroke velocity.

## Typography

The typographic architecture balances three distinct technical voices:
- **Headlines (`Space Grotesk`):** High-tension, futuristic sans-serif displaying computational authority. Used for operational mode indicators, tilt thresholds, and core system telemetry dashboards.
- **Body & Interface (`Geist`):** Crisp, mathematically neutral sans-serif built specifically for technical tooling. Delivers high density with effortless micro-legibility in nested trees, settings panels, and documentation.
- **Telemetry & Labels (`JetBrains Mono`):** Exacting monospace used for bio-metric sensor readouts, git commit correlations, CPU/tilt metrics, timestamps, and active shell data.

### Formatting Rules
- Use `label-caps` strictly uppercase for system telemetry tags, connection nodes, and state monikers (e.g., `FLOW_STATE::ACTIVE`, `HRV_DELTA`).
- Numerical counters and volatile operational data must strictly consume `JetBrains Mono` with tabular lining figures enabled (`tnum`) to eliminate layout reflow.

## Layout & Spacing

The layout is built on a 12-column adaptive fluid computational grid that expands edge-to-edge with locked shell sidebars:
- **Desktop (1280px+):** 12 columns, `1.25rem` (20px) gutters, `2rem` (32px) margins. HUD layout features a 72px static left telemetry spine, a modular central cockpit, and an optional 320px cognitive stream drawer.
- **Tablet (768px - 1279px):** 8 columns, `1rem` (16px) gutters, `1.5rem` (24px) margins. Cognitive stream auto-collapses to an overlay drawer.
- **Mobile (< 768px):** 4 columns, `0.75rem` (12px) gutters, `1rem` (16px) margins. Pinned bottom HUD navigation bar with full-width stack cards.

### Spacing Principles
- Density is tightly tuned: use `space-xs` and `space-sm` inside cards, telemetry pills, and table views to maintain maximum data density without visual clutter.
- Maintain `space-lg` to `space-xl` between isolated bio-telemetry domains (e.g., separating Neural Load Graphs from the Git Velocity stream).

## Elevation & Depth

Visual hierarchy is executed via **Translucent Specular Glassmorphism** layered directly above background biological shaders:

1. **Layer 0 (Void Canvas):** Base `#09090B` host surface containing ambient, low-pass radial blurs ("organic cognitive blobs") that pulse slowly according to cognitive state (e.g., a slow `#2DD4BF` sine pulse in zen, or rapid, chaotic `#F43F5E` orbits during tilt).
2. **Layer 1 (Glass Panels & Workspaces):** 
   - Background: `rgba(18, 18, 22, 0.65)`.
   - Backdrop filter: `blur(16px) saturate(140%)`.
   - Edge: Micro-frosted highlight border `1px solid rgba(255, 255, 255, 0.07)`.
   - Inner glow: Inset `0 1px 0 0 rgba(255, 255, 255, 0.12)`.
3. **Layer 2 (Floating Popovers, Terminals & Modals):**
   - Background: `rgba(24, 24, 27, 0.85)`.
   - Backdrop filter: `blur(24px) saturate(160%)`.
   - Border: `1px solid rgba(255, 255, 255, 0.14)`.
   - Ambient Shadow: `0 16px 40px -8px rgba(0, 0, 0, 0.85), 0 0 20px -2px var(--active-state-glow)`.
4. **Layer 3 (Glowing Telemetry Indicators & Cursors):** High-luminance nodes featuring intense localized glow: `box-shadow: 0 0 12px var(--color-primary-glow)`.

## Shapes

This design system employs a **Sleek Cybernetic Softness** (`roundedness: 1`):
- Base container radius is `0.25rem` (4px) to `0.5rem` (8px). 
- Primary content panels and data tiles utilize a disciplined `0.5rem` (`rounded-lg`) border radius, preserving the sharp, architectural silhouette of code editors.
- Interactive buttons and inputs use `0.375rem` (6px) to remain tactile yet clinical.
- **Pill Exception:** Sensor telemetry badges, flow mode switchers, and real-time state alerts explicitly use full continuous pill rounding (`9999px`) to create organic contrast against rigid workspace grids.

## Components

### Buttons & Interactive Triggers
- **Zen / Primary Action:** Filled with translucent teal `rgba(45, 212, 191, 0.15)`, bordered by `1px solid rgba(45, 212, 191, 0.4)`, text color `#2DD4BF`. Hover transitions to solid `#2DD4BF` with `#09090B` text and `0 0 20px rgba(45, 212, 191, 0.45)` aura.
- **Flow / Secondary Action:** Purple-cyan gradient keyline over frosted black glass with electric violet hover response.
- **Ghost Action:** Borderless, `text-zinc-400`, hover provides `rgba(255, 255, 255, 0.05)` subtle fill.

### Glowing Status Pills
- Pill-shaped container (`rounded-full`) styled with `backdrop-blur-md` and `1px solid rgba(255, 255, 255, 0.1)`.
- Features an embedded 6px pulsating circular beacon with active `ping` glow animation.
- Dynamic states:
  - `ZEN`: Teal beacon, teal text, `rgba(45, 212, 191, 0.08)` background.
  - `FLOW`: Purple/Cyan beacon, cyan text, `rgba(168, 85, 247, 0.08)` background.
  - `MELTDOWN_RISK`: Rapid amber-red flash, crimson text, `rgba(244, 63, 94, 0.12)` background.

### Cognitive Telemetry Cards
- Encased in glassmorphic panels with top-edge specular gradient highlighting (`inset 0 1px 0 rgba(255, 255, 255, 0.1)`).
- Card headers feature uppercase `label-caps` monospace labels alongside biometric mini-graphs.
- Interactive cards elevate on hover with border illumination reflecting current system state.

### Lists & Telemetry Streams
- Borderless rows separated by `1px solid rgba(255, 255, 255, 0.03)`.
- Alternating subtle hovers using `rgba(255, 255, 255, 0.02)`.
- Left-aligned monospace timestamps in `telemetry-sm` (`#71717A`), followed by categorized event tokens.

### Input Fields & Terminal Consoles
- Darkened inset backgrounds (`rgba(0, 0, 0, 0.45)`) to communicate physical depth within the glass surface.
- Border: `1px solid rgba(255, 255, 255, 0.08)`.
- Focus state: Border illuminates to `#2DD4BF` with an inner shadow `inset 0 0 8px rgba(45, 212, 191, 0.2)` and clean monospace text rendering.

### Organic Cognitive Blobs (Specialized Component)
- Hardware-accelerated background SVG/WebGL mesh nodes with smooth morphing paths.
- Positioned strictly behind the glass workspace with a high Gaussian blur (`blur-3xl`, 64px–128px radius).
- Dynamics: Frequency and rotation correlate directly to keyboard APM and tilt sensor inputs.
